# Выводы нового RAG по научным статьям

Действующий корпус: полные MemGPT, MemoryBank и Generative Agents, а не
документация Domovoy. Оригинальный индекс недели 6 из 182 чанков скопирован
без изменения байтов. PDF, hashes, страницы и UTF-16 цитаты проверены;
свежая локальная пересборка также создаёт 182 чанка. Все 15 controller/provenance
тестов пройдены; тестовые fixtures не выдаются за доказательство качества LLM.

Собственный Agent использует direct HTTP Chat API Tiel Coder Q8, локальные
Ollama embeddings, NumPy retrieval и необязательный BGE. В обычном режиме
облако и веб выключены. Веб-проверка трёх закреплённых arXiv PDF подтвердила
одинаковые bytes/hashes и отсутствие более новых версий на момент проверки.
Это не проверка научной истинности.

M1 переиспользует реальные Q8/B repeat0 ответы дня29; второй проход B дал
2/10 correct, 1 галлюцинацию и совпадение verdict в 9/10 вопросов.

Самопроверка первого draft и одна доработка не устранили пропуски и неверные
цитаты. После доработки второго semantic review нет. Эти результаты не
позволяют обещать безошибочные ответы на сложные вопросы по статьям.
Контрольный набор известен заранее и не является скрытым тестом обобщения.

Облачное сравнение выполнено на проверенном API ID `deepseek-flash`: 2/10
correct, 2 partial, 5 ошибок строгой валидации цитат, 0 найденных фактических
галлюцинаций. Полное среднее время: M0 9.89 s, M1 63.49 s, M2 55.16 s,

а не доказательство, что облачная модель хуже знает статьи.

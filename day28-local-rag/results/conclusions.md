# Выводы локального RAG v2

На независимом новом наборе20вопросов × два прохода основной Agent82 дал
**36/40 correct (90%)**, три ответа с неподтверждёнными фактами, ноль delivery
failures и ноль обрезанных генераций. По проходам17/20 и19/20; verdict совпал
в18/20 парах. Восемь правильных отказов входят вcorrect; по сведениям статей
correct28/32. Expected facts не передавались модели. Самопроверка не oracle.

Среднее полное время79.38с, backend generation27.15tokens/s. Q8/optimized,
три слота по32768, с параллельными проверками; это не controlled speed comparison.
Память в новой серии отдельно не измерялась. [Таблица и SHA](quality-v2/comparison.md).

База — полные MemGPT2310.08560v2, MemoryBank2305.10250v3 и GenerativeAgents
2304.03442v2. Оригинальный индекс недели6:182чанка,1024D, неизменённые bytes/
vectors/UTF-16 spans; PDF pages и ревизии проверены. Документация Domovoy
не входит в действующий retrieval. Подробности: [PROVENANCE](../PROVENANCE.md).

Теперь retrieval объединяет Qwen dense embeddings и собственный BM25 через
weightedRRF. Generic topic prefix удалён; четыре опорных чанка получают соседний
канонический контекст. Agent планирует части вопроса, переводит search queries,
возвращает все части, выбирает ID цитат; программа материализует exactquotes.
Далее проверка полноты и поддержки, одна доработка, окончательная проверка.
Все calls/catalogs/review inputs/finish_reason/usage сохраняются. Облако и web off.

Дополнительный focus filter отклонён: paired40 дали34/40 correct, теже3 ошибки,
два ухудшения и ниодного улучшения. Удалял запрошенные сведения; не устранил
неподтверждённые факты. Это36 дополнительных реальных calls на готовых ответах,
а не новый end-to-end прогон. Код/ответы/оценки эксперимента сохранены вquality-v2,
основной Agent возвращён к измеренному82.

Остались три неподтверждённых утверждения: вдвух ответах GPT-4 как фактически
использованный judge; водном psychological tuning распространяется наChatGPT.
Ещё один ответ пропускает open-source scope. Есть отдельные языковые недостатки.
Цель≥80% достигнута; ноль неподтверждённых фактов не достигнут.

Свежий HTTPS диалог того жеcore82: основные вопросы4/4 правильны,
полная selected-quote support2/4, фактических галлюцинаций нет. Это дополнительный
сетевой диалог, а не новые независимые20вопросов. [День30](../../day30-private-service/results/conclusions.md).

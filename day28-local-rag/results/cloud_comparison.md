M1 использует B/repeat0 контролируемой матрицы дня29. Второй проход B оценивает стабильность. M0/M2 и B запускались последовательно в разные моменты; возможный временной confound не исключён.

В DeepSeek используется тот же собственный Agent и локальный dense retrieval. JSON mode провайдера отличается от локального schema decoder; токенизаторы и provider context различаются. Tiel template — только общий reference budget, usage облака берётся из API. Cloud wall time включает HTTP, очередь и prefill: отдельная backend tokens/s не выдумывается.

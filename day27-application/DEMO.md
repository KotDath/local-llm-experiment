# Демонстрация дня 27

Фрагмент общего видео: ориентир 1:00–2:00.

1. Открыть `agent.py` и `model.py`: состояние агента и HTTP Chat API без SDK.
2. Запустить `python3.12 bot.py` (единственный poller данного токена).
3. В Telegram отправить `/start`, затем «Какая столица Франции?» и follow-up.
4. Выполнить тот же вопрос через `python3.12 cli.py ask ...`.
5. В JSONL показать создание двух сессий, message и reset — доказательство
   доступности агента для автономной проверки.
6. Показать независимые результаты; пояснить локальность inference и канал Telegram.

Не показывать `.env`, TG token, реальные user IDs и VPS credentials.

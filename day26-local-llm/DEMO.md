# Демонстрация дня 26

Фрагмент общего видео: ориентир 0:00–1:00; при медленном запуске увеличить время.

1. Показать `run_model.sh`: loopback, путь Q8, Vulkan, текущие 32768 tokens/slot.
   Для прямого verify_day26.py резерв ответа 6144, temperature 1; Agent
   отдельно использует baseline 65536/8192 и optimized 32768/6144.
2. Запустить модель или показать уже запущенный собственный процесс и health.
3. Выполнить `python3.12 verify_day26.py`, показать три живых ответа.
4. Указать арифметическую ошибку сложного ответа: правильный срок 8 ч.
   Не представлять ошибочный ответ как правильный.
5. Открыть `results/day26.jsonl`: actual usage и timings, совпадение model hash.
6. Коротко показать `agent.py` и `protocol.py`: самостоятельная сущность,
   прямой Chat API, stdin/stdout без Telegram и agent SDK.

Резервный повтор: `python3.12 cli.py ask 'Какая столица Франции?' --json`.
Секретов в этом фрагменте нет. Не показывать `.env` других версий.
